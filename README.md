# BAVA.AI
Bava – AI Voice Assistant 🤖

Bava is a beginner-friendly Python AI voice assistant that can understand voice or text commands and respond using text-to-speech.

Features

- 🎤 Voice command recognition
- 🔊 Voice responses using "pyttsx3"
- 🕐 Tells the current time
- 🌐 Opens websites like YouTube, Instagram, Spotify, GitHub, and Google
- 🔎 Searches Google for unknown questions
- 💬 Responds to predefined questions and commands
- 🚪 Exit command to close the assistant

Technologies Used

- Python
- SpeechRecognition
- Pyttsx3
- Google Speech Recognition
- Web browser
